# Security policy / Politique de sécurité

## English

### Reporting a vulnerability

**Do not describe a security flaw in a public issue.** Issues are public: anyone could read the details before a fix
exists.

Report it privately, in one of two ways:

- on GitHub, with private vulnerability reporting: tab **Security**, then **Report a vulnerability**
  (<https://github.com/prevo-pro/prevo/security/advisories/new>);
- or by e-mail to **contact@prevo.pro**, saying that you want to report a security flaw in Prévo.

Do not send real company data, passwords, tokens, cookies, AI keys, or the content of the `donnees/acces/` folder or
of `prevo.config.json`. You will get an answer before any detail is made public.

### Supported versions

| Version | Receives security fixes |
|---|---|
| 2.0.x (current) | Yes |
| 1.2.x (previous stable, currently 1.2.1) | Yes |
| 2.0.0 betas | No: update to 2.0.0 |
| Earlier versions | No: please update |

## Français

### Signaler une faille

**Ne décrivez pas une faille de sécurité dans une issue publique.** Les issues sont publiques : n'importe qui pourrait
lire les détails avant qu'un correctif existe.

Signalez-la en privé, de l'une de ces deux façons :

- sur GitHub, par le signalement privé des failles : onglet **Security**, puis **Report a vulnerability**
  (<https://github.com/prevo-pro/prevo/security/advisories/new>) ;
- ou par courriel à **contact@prevo.pro**, en indiquant que vous voulez signaler une faille de sécurité dans Prévo.

N'envoyez ni données réelles d'entreprise, ni mots de passe, ni jetons, ni cookies, ni clés d'IA, ni le contenu du
dossier `donnees/acces/` ou de `prevo.config.json`. Vous aurez une réponse avant que le moindre détail soit rendu
public.

### Versions qui reçoivent des correctifs

| Version | Correctifs de sécurité |
|---|---|
| 2.0.x (actuelle) | Oui |
| 1.2.x (stable précédente, actuellement 1.2.1) | Oui |
| Bêtas de la 2.0.0 | Non : passez à la 2.0.0 |
| Versions antérieures | Non : mettez à jour |
